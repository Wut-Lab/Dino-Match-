# Dino art sources

All dinosaur art comes from [Openclipart](https://openclipart.org), where every
upload is released under **CC0 1.0** (public domain). CC0 needs no attribution and
no license notice, and allows changes and commercial use. This file is here only
to record where the art came from.

The unmodified originals are in `source/`. `tools/build-art.py` recolours and
remixes them into `js/dino-art.js`, and marks each dino's eyes so they can blink.
